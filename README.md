# playwright-automation-framework
### NPM Scripts
- `npm test` → run all projects (ui + api)
- `npm run test:headed` → run with browser UI
- `npm run test:ui` → run a single UI project
- `npm run test:api` → run a single API project
- `npm run debug` → open Playwright Inspector
- `npm run report` → open saved HTML report
- `npm run trace:show` → open a .zip trace
